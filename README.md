# 🕷️ Multiverso_Spider-Man

## 📌 Sobre o Projeto

**Multiverso_Spider-Man** é um site desenvolvido como parte das aulas da **DIO (Digital Innovation One)**, com o objetivo de praticar e consolidar conhecimentos em desenvolvimento web.

O projeto é totalmente inspirado no conceito do **Multiverso do Homem-Aranha**, apresentando os **três Homens-Aranha do cinema**, cada um com sua própria identidade, história e estilo.

O site foi pensado para ser visual, interativo e nostálgico, reunindo informações, trailers e imagens de cada versão do herói.

---

## 🕸️ Conteúdo do Site

O site é dividido em seções dedicadas a cada Homem-Aranha:

### 🕷️ Spider-Man (Tobey Maguire)

* Seção exclusiva dedicada ao primeiro Homem-Aranha do cinema
* Imagens icônicas dos filmes
* Trailer oficial
* Destaque para a origem clássica do herói

### 🕷️ The Amazing Spider-Man (Andrew Garfield)

* Área dedicada à versão mais moderna e emocional do personagem
* Galeria de imagens
* Trailer dos filmes
* Ênfase no estilo e personalidade únicos

### 🕷️ Spider-Man (Tom Holland)

* Seção focada no Homem-Aranha do MCU
* Imagens e trailers
* Integração com o universo da Marvel
* Abordagem mais jovem e tecnológica

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Conceitos aprendidos nas aulas da **DIO**

---

## 🎯 Objetivo do Projeto

* Praticar estruturação de páginas web
* Trabalhar organização de conteúdo
* Aplicar conceitos de design e interatividade
* Criar um projeto temático para portfólio
